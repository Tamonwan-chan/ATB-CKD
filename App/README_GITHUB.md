# คู่มือทดลองใช้ — เครื่องมือคำนวณขนาดยาฆ่าเชื้อตามการทำงานของไต

ขอบคุณที่ช่วยทดลองใช้โปรแกรมนี้ 🙏 เอกสารนี้อธิบายว่าโปรแกรมทำอะไร ใช้อย่างไร และอยากให้ช่วยดูจุดไหนบ้าง

> โปรแกรมนี้เป็น **ฉบับทดลอง (เวอร์ชันทดสอบ)** เพื่อขอความเห็นก่อนใช้งานจริง ยังไม่ใช้เป็นคำสั่งใช้ยากับผู้ป่วย

## เปิดใช้อย่างไร

- เปิดจาก **ลิงก์** ที่ได้รับ (ทางเดียวก็ใช้ได้ ทั้งมือถือและคอมพิวเตอร์)
- บนมือถือ กด “เพิ่มไปยังหน้าจอโฮม” (Add to Home Screen) จะเปิดง่ายเหมือนแอป
- ไม่ต้องล็อกอิน ไม่ต้องกรอกข้อมูลผู้ป่วย โปรแกรมไม่เก็บข้อมูลใด ๆ

## โปรแกรมช่วยอะไร

มี 2 แท็บด้านบน:

1. **ยาปฏิชีวนะฉีด (IV)** — คำนวณค่าการทำงานของไต (CrCl แบบ Cockcroft-Gault) จากเพศ/อายุ/น้ำหนัก/Scr แล้วแสดงขนาดยาที่ปรับตามไต
2. **ยาวัณโรค (TB)** — คำนวณขนาดยาวัณโรค (H, R, Z, E และยาสำรอง S, Lfx, Am) ตามน้ำหนักตัว พร้อมปรับเมื่อไตเสื่อม

## วิธีใช้ทีละขั้น

**แท็บ IV**
1. เลือกเพศ กรอกอายุ น้ำหนัก และค่า Scr (mg/dL)
2. พิมพ์ชื่อยาในช่องค้นหา (ไทยหรืออังกฤษ) แล้วเลือกจากรายการที่ขึ้นมา
3. กด **คำนวณ** จะเห็นค่า CrCl, ขนาดยาปกติ, ขนาดที่ปรับแล้ว และกด “ดูทุกช่วง CrCl” เพื่อดูทุกระดับได้

**แท็บ TB**
1. กรอกน้ำหนัก (และกรอก Scr/อายุ/เพศ ถ้ามี เพื่อให้ประเมินไตอัตโนมัติ)
2. ถ้าไม่ได้กรอก Scr ให้เลือกสถานะไตเอง (ปกติ / CrCl<30 หรือฟอกไต)
3. กด **คำนวณ** จะเห็นขนาดยาแต่ละตัวตามน้ำหนัก และตัวช่วยคูณ มก./กก. ให้

## จุดที่อยากให้ช่วยดู

- ตัวเลข/ขนาดยา ตรงกับที่ใช้จริงหรือไม่ โดยเฉพาะรายการที่ขึ้นป้าย **“ตรวจสอบ”** (เช่น Streptomycin, Amikacin) ซึ่งยังไม่ยืนยันขนาด
- ใช้งานบนมือถือสะดวกไหม อ่านง่ายไหม ปุ่มกดง่ายไหม
- มีคำ/ข้อความไหนที่ทำให้เข้าใจผิดได้บ้าง
- ควรเพิ่ม/ลดยารายการใด

## ข้อควรระวัง (สำคัญ)

- เป็น **เครื่องมือช่วยตัดสินใจ** ไม่ใช่คำสั่งใช้ยา ต้องตรวจสอบกับแหล่งอ้างอิงและใช้วิจารณญาณเสมอ
- ใช้กับ **ผู้ใหญ่** เท่านั้น (โปรแกรมจะไม่คำนวณถ้าอายุ < 16 ปี)
- แท็บ IV: ไม่ครอบคลุมผู้ป่วยฟอกไต/บำบัดทดแทนไต และหญิงตั้งครรภ์
- แท็บ TB: น้ำหนัก < 30 กก. หรือเด็ก ให้ใช้ตารางขนาดยาเด็ก
- อ้างอิง: UpToDate/Lexicomp (ยาฉีด) และแนวทางการควบคุมวัณโรคประเทศไทย พ.ศ. 2564 (ยาวัณโรค)
