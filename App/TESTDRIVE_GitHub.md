# วิธีนำโปรแกรมขึ้น GitHub Pages (ไฟล์เดียว)

โปรแกรมทั้งหมดอยู่ในโฟลเดอร์ **`docs/`** ที่ชั้นนอกสุดของรีโป (ไฟล์หลักคือ `docs/index.html` ข้อมูลยาฝังอยู่ในไฟล์แล้ว) ส่วน `manifest.json`, `sw.js` และไอคอนอยู่ในโฟลเดอร์เดียวกัน

## การตั้งค่า (ทำไว้แล้ว)

- รีโป: `github.com/Tamonwan-chan/ATB-CKD` (Public)
- **Settings → Pages**: Source **Deploy from a branch** · Branch **main** · โฟลเดอร์ **/docs**
- ลิงก์: `https://tamonwan-chan.github.io/ATB-CKD/`
  - คัดลอกลิงก์ส่งทาง LINE ได้เลย · บนมือถือกด "เพิ่มไปยังหน้าจอโฮม" จะใช้เหมือนแอป

## เวลาต้องการอัปเดตโปรแกรมหรือข้อมูลยา

1. แก้ไฟล์ `docs/index.html` แล้ว `git push` (หรือแก้ในเว็บ github.com แล้วกด Commit)
2. GitHub จะเผยแพร่เวอร์ชันใหม่ให้เองภายในประมาณ 1 นาที ไม่ต้องอัปโหลดไฟล์เอง
3. ผู้ใช้จะเห็นเวอร์ชันใหม่เมื่อเปิดลิงก์ครั้งถัดไป (ถ้าอยากเห็นทันทีให้กดรีเฟรชแรง ๆ)

## เรื่องที่ควรรู้

- **ส่ง "ลิงก์" อย่าส่ง "ไฟล์"** — คนที่เปิดจากลิงก์จะได้เวอร์ชันล่าสุดเสมอ ส่วนไฟล์ที่บันทึกลงเครื่องจะค้างเป็นเวอร์ชันเก่า
- ถ้าเปิดลิงก์แล้วขึ้นหน้า README แทนโปรแกรม แปลว่าไฟล์โปรแกรมไม่ได้ชื่อ `index.html` — ให้เปลี่ยนชื่อไฟล์ในรีโปเป็น `index.html` (กดที่ไฟล์ → ✏️ Edit → แก้ชื่อ → Commit)
- ตอนนี้เป็นเวอร์ชันทดลอง รายการที่ติดป้าย `ตรวจสอบ` (Streptomycin, Amikacin) ยังไม่ยืนยันขนาดยา
- โปรแกรมไม่เก็บข้อมูลผู้ป่วยและไม่บันทึกการใช้งาน การเปิดเป็นลิงก์สาธารณะจึงปลอดภัย
